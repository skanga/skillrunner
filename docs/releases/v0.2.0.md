# Skill Runner v0.2.0

A usability-focused release with guided setup, earlier capability checks, clearer diagnostics, and safer operational workflows.

## Highlights

- `skillrun init` creates a minimal local or authenticated configuration and a text-only starter skill without overwriting existing files.
- `skillrun config show` displays effective settings and their sources; `--version` reports the installed version.
- Configuration errors identify safe field locations and next actions. JSON mode also covers command-line parsing failures.
- `skillrun doctor` performs independent offline readiness checks. `doctor --network` explicitly opts into a model tool-calling probe.
- Fully configured models skip implicit metadata discovery. Requested output validators and configured dependencies are checked before model execution.
- Text reads are paged against remaining context, with explicit continuation metadata. Runs show progress, retries, budget usage, and a heartbeat; `--quiet` suppresses progress.
- Primary answers are retained as clean artifacts, separate from diagnostic reports, with usable format extensions.
- `--output-file` and `--output-directory` provide unambiguous publication destinations. The latter creates missing directories.
- `--model-alias` selects a named profile without inheriting `OPENAI_BASE_URL`; ambient direct-endpoint selection emits a warning.
- `inputs preview` and repeatable `--exclude` options make input selection explicit and inspectable.
- Model and HTTP MCP profiles support explicit proxy and CA-bundle configuration, without ambient proxy or credential inheritance.
- `runs list` reports bundle status and disk usage. `runs clean` previews cleanup; `--yes` confirms deletion of completed bundles while active, unfinished, linked, and unknown bundles remain excluded.
- Documentation now starts with a minimal successful workflow and separates historical qualification evidence from current usage.

## Upgrade notes

- **Doctor is offline by default.** Scripts requiring a connectivity/tool-calling check must use `skillrun doctor --network`.
- **Nonempty `policy.allowed_env` is rejected.** Replace it with explicit `policy.command_env.<executable>` mappings. Empty legacy lists remain accepted.
- **Primary output paths have changed.** Use `primary_output` from the receipt instead of assuming the deliverable is `result.md` or has an extensionless artifact filename. `result.md` remains the diagnostic report.
- JSON stdout stays machine-readable, but normal runs now show progress on stderr. Use `--quiet` when only errors and the receipt are wanted.
- Legacy `--output` semantics remain supported. Choose only one of `--output`, `--output-file`, and `--output-directory`.
- Explicit output filenames in prompts can now supply the inferred format when no format or output-file extension is supplied. External formats still require an installed, allowlisted validator.
- Text accounting remains a conservative UTF-8-byte estimate. Pagination does not provide unlimited context or silently discard required history; large tasks need suitable model capacities and budgets.
- Content logging is opt-in, but prompts, reports, and artifacts are still retained in run bundles. Input exclusions are never inferred automatically.

## Install

Download the release wheel and verify it using the attached `SHA256SUMS`, then:

```console
uv tool install --reinstall ./skillrunner-0.2.0-py3-none-any.whl
skillrun --version
skillrun --help
```

Python 3.13 or later is required. See the README for initialization and model configuration.
